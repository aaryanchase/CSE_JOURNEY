# 🧠 Learning Philosophy

I'm trying to follow a simple principle:

> **Don't just learn the syntax. Understand what is happening.**

For the technologies I learn, I want to understand:

1. **What** it is
2. **Why** it exists
3. **How** it works
4. **When** to use it
5. **How** to build with it

I also want to avoid constantly jumping between technologies without building a solid foundation.

My general learning cycle is:

```text
Learn
  ↓
Practice
  ↓
Build
  ↓
Break
  ↓
Debug
  ↓
Understand
  ↓
Improve
  ↓
Repeat
```

# 📝 Why I Created This Repository

Learning Computer Science is a long process.

There will be days when progress feels fast and days when a simple programming problem takes hours to understand.

This repository is meant to capture **both**.

I don't want to record only polished projects. I also want to preserve the smaller programs, experiments, notes, mistakes, debugging sessions, and improvements that show how I got there.

Years from now, I want to look back at this repository and see the progression from my first programming exercises to more complex software, AI, and robotics projects.
